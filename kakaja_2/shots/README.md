# Screenshots

`tier-high.png` / `tier-low.png` are the two ends of the quality ladder, same
throw, same framing — the pair the NOTES refer to. Note that the low tier has no
shadow map: what grounds the dice there is the fake contact blob.

Everything else the harnesses write lands here too and is regenerated on each
run (`tools/test.mjs`, `tools/faces.mjs`, `tools/tiershots.mjs`), so this folder
is disposable apart from these two.
